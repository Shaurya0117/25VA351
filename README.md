## Structure

### `class-progress/`
Day-wise code written during class — raw practice files, one per session, named by date/topic (e.g. `day01-variables.js`, `day02-functions.js`). Shows the learning trail as it happens.

### `revision/`
Concept notes and summaries for topics I revisit — arrays, DOM manipulation, closures, async/await, etc. Written in Markdown so they double as quick-reference cheat sheets.

### `mini-projects/`
Small standalone builds that apply what I've learned — each in its own folder with its own README describing what it does, tech used, and how to run it.
